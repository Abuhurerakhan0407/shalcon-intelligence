## Allowed proof before clients

- Working demo recordings.
- Test run counts.
- Test success/failure rates.
- Response latency measured in a controlled demo.
- Integration coverage.
- Workflow diagrams.
- Human escalation behavior.
- Audit logging.
- Screenshots/video of real system behavior using synthetic data.

## Required for client-result claims

Record:
- client/company,
- permission to publish,
- baseline period,
- post-launch period,
- exact metric definition,
- data source,
- sample size/volume,
- calculation method,
- relevant caveats,
- proof artifact/link.
