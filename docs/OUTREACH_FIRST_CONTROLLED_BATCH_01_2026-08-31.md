## What to record after each actual send
In live Google Sheet:
- Stage → `Sent` only after the message actually leaves;
- Last Touch → real send date;
- Next Action → monitor reply / follow-up step;
- Next Follow-up → based on agreed cadence;
- Notes → concise outcome only, not full private conversation unless operationally necessary.

## First-batch learning questions
Do not judge success only by replies. Record:
1. Did the recipient accept/view/respond where observable?
2. Was the workflow observation understood as relevant?
3. Did anyone interpret the message as a generic chatbot pitch?
4. What language did prospects use for the problem/workaround?
5. Was the CTA small enough?
6. Which subsegment produced the clearest signal?
7. Any opt-out/negative relevance signal?

After a small real sample, improve messaging from repeated evidence—not from hypothetical copy optimization.
